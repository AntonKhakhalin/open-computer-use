## What's Changed

* CI and reliability: added a GitHub-hosted macOS validation workflow (`macos-26`) that builds the app and runs the full Swift test suite in CI, with live GUI tests gated behind `OCU_RUN_LIVE_TESTS`; hardened macOS window discovery (private `_AXUIElementGetWindow` identity resolution with safe degradation, explicit same-bounds ambiguity instead of guessing, minimized-window discovery in `list_windows`), and fixed the test-target compile errors the new CI surfaced.
* Setup: new `ocu setup` command that detects Codex, Claude Code, OpenCode, Gemini CLI, and Cursor in one step, is idempotent, and never silently overwrites unrelated configuration (`--dry-run`, `--all`, `--agents` flags).
* Public presentation and documentation: fork-aware README hero and capability / known-limitation sections, short-link install paths, `ocu setup` sections, minimized-window capability notes with caveat, macOS CI documentation in `docs/CICD.md`, demo plan, and repository documentation standardized on English.
