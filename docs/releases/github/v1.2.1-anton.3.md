## What's Changed

* macOS runtime is now single-process: the MCP server and CLI execute automation directly in the launched `Open Computer Use.app` binary, with the same Accessibility / Screen Recording identity as before. The background helper agent and its unix socket are gone from the default path, eliminating the stale-agent failure mode ("agent closed the connection") caused by orphaned helper processes holding the socket. The legacy proxy remains available for one release behind `OPEN_COMPUTER_USE_AGENT_PROXY=1`. ([#2](https://github.com/AntonKhakhalin/open-computer-use/pull/2))
* macOS smoke and app discovery hardened: running the test suite under agent-style parents (Codex / OpenCode shells, some CI runners) no longer drops the fixture app from `list_apps` — the fixture is packaged as a real app bundle, and discovery pins its identity by executable path ahead of any inherited parent identity. ([#2](https://github.com/AntonKhakhalin/open-computer-use/pull/2))
