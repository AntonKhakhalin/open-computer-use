## What's Changed

* Fork distribution release: this is the first release of the `AntonKhakhalin/open-computer-use` fork, combining the upstream v1.2.0 base with native macOS `launch_app` (proposed upstream in PR #2) and native macOS window management with window-targeted actions (proposed upstream in PR #3), including exact CGWindowID window identity, same-bounds disambiguation, closed/ghost-window rejection, and `screenshotId`-gated coordinate actions on macOS.
* Multi-agent install surface: fork npm package `@antonkhakhalin/open-computer-use` (bundled runtimes for all supported platforms), new Cursor MCP installer (`install-cursor-mcp`, standard `mcp.json` format), new `install-local-runtime.sh` build-from-source installer, fork skill URLs for the `skills` CLI, and MCP Registry metadata (`io.github.AntonKhakhalin/open-computer-use`) validated against the official 2025-12-11 server schema.
* Documentation: fork-aware README (English + zh-CN) with verified capability and known-limitation sections, skill installation reference updated for fork install paths and the runtime / MCP / skill distinction, macOS input-delivery and background-operation best practices in the agent skill, and reusable public launch copy in `docs/PUBLIC_LAUNCH.md`.
